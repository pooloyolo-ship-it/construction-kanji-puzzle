# 建設用語パズル — 初級・中級・上級各3モード ランダム生成版

HTML・CSS・JavaScriptの静的Webアプリです。提供された `data/construction_terms_200.json` の200語を実行時に読み込みます。外部サーバー、データベース、ログイン、実行時ライブラリは不要です。

## 起動と配布

このフォルダーで `npm run serve` を実行し、http://localhost:4173 を開きます。開発用Node.jsは22以降です。JSON・ES Modules・Workerを使用するため、HTMLの直接ダブルクリックでは起動できません。

GitHub Pagesでは `index.html`、`css/`、`js/`、`data/construction_terms_200.json`、`data/fallbacks.json`、`.nojekyll` を公開ルートに配置します。ビルド不要、相対パスです。GitHubへの公開操作は未実施です。

## 初級3モード（中級の設定は後述）

- 初級1：beginner1の2文字語11語＋初心者向けホワイトリストの3文字語1語。ヒントあり。
- 初級2：beginner1・beginner2から2～4文字を抽選。ヒントあり。
- 初級3：初級2と同じ用語構成。ヒントなし。

初級2・3は、A（4文字2語＋3文字1語＋2文字7語）、B（4文字1語＋3文字3語＋2文字6語）、C（3文字3語＋2文字8語）をランダムに選びます。Cは指定例に従い4文字語を含みません。同じ用語を正解セット内で重複選択しません。

「最初から」は現在の用語セットと初期配置に戻すだけです。「新しい問題」と「新しい問題でもう一度」は、用語セットと配置の両方を再生成します。直前の問題の用語セットと盤面をモードごとに記憶し、同じ問題を連続出題しません。記憶はページ内だけです。

## 生成とクリア可能性の保証

1. 構成パターンを選び、該当する辞書から正解セットを抽選。
2. 漢字に分解し、初級25文字・中級36文字ちょうどになることを確認。
3. 全漢字をシャッフル。
4. 盤面の文字で作れる全辞書語を判定対象に設定。初期盤面に完成語があれば再シャッフル。
5. 実際の長語優先・同時自動消去ルールを使い、選択した正解セットで全消しする交換ルートを探索。
6. 保存された証明ルートをゲームエンジンで再生し、警告ありのモードでは手詰まり警告にも阻まれず全消しできることを検証してから出題。

文字数だけで「必ず解ける」とは扱いません。全消しルートが見つからないセット・配置は採用しません。構成抽選は最大30回、各セットのシャッフルは最大35回、ルートの配置探索は最大2400試行です。一定回数で生成できなければ、モードごとに3つ登録した検証済み予備問題から直前と異なるセットを使います。

生成はWeb Workerで行い、画面スレッドを止めません。Worker起動失敗や5秒の待機上限でも予備問題でプレイ可能にします。予備問題は `data/fallbacks.json` にあり、起動時にもルートを検証します。

## 操作と判定

マウス・タッチのPointer Eventsで任意のマスを交換します。2マスを順にクリック・タップする交換とキーボード操作も対応しています。空白への移動では移動元が空白になります。文字の落下・補充はありません。

方向は左→右、上→下だけです。長語優先で、完全に含まれる短い用語を除外します。別の場所の用語や一部だけ交差する用語は同時消去し、共有マスは一度だけ消します。初期盤面には完成語がなく、開始時の消去は行いません。

その問題の選択語だけでなく、初期文字で構成可能な2～5文字の全辞書語（他のlevelを含む）も認識します。5×5に並ばない6文字語や、その問題にない漢字を使う語は対象外です。実行時の判定辞書は提供200語で、旧固定版の補助用語4語は追加しません。

用語ごとの使用上限は初期文字個数から算出します。生成時の正解セットは重複語なしですが、別解で同一語を複数回使える文字個数があれば対応します。

## 手詰まり判定

消去結果を仮計算し、残り漢字の個数と各辞書語の残り使用回数から、すべて使い切る組み合わせをバックトラッキングで探索します。固定禁止語リストや選択セットだけを使う判定ではありません。別の辞書語で全消しできる場合も許可します。

探索は成立可能語への絞り込み、少ない候補しか持たない文字からの探索、残り文字数による枝刈り、残り文字＋使用回数のメモ化を使います。辞書は先頭文字・文字数・levelで索引化しています。

組み合わせがなければ交換全体を取り消し、警告を表示します。盤面、完成用語、使用回数、戻す履歴は操作前のままです。危険な消去は演出しません。全初級で有効で、中級・上級用の難易度設定では無効にできます。

この可否判定は指定されたマルチセット分解ルールに従います。共有文字を重複消去することだけが唯一の全消し方法となる特殊な辞書・ルールへ拡張する場合は、判定アルゴリズムの拡張が必要です。

## ヒントと学習表示

初級1・2のヒントは、まだ消しておらず残り文字で作れる選択用語を1語だけ表示します。位置、行・列、移動手順は教えません。初級3ではボタンを非表示にします。別解で選択語の文字を使い切り、候補がなくなった場合は、残り文字から別の用語を探す案内だけ表示します。

クリア後は、その問題の生成に使った正解セット全語と辞書の解説を表示します。プレイ中は用語一覧・解説・証明ルートを表示しません。

## 演出と履歴

完成マスを強調して少し拡大し、約0.39秒表示した後、約0.26秒でフェードアウトします。演出中は文字操作、ヒント、戻す、最初から、新問題、選択画面への移動を止めます。動きを減らす端末設定では拡大を省きます。

交換と同時消去を1回の履歴として保存し、一手戻すは文字、空白、消去状態、完成履歴、使用回数を完全復元します。警告で拒否した操作は履歴に残しません。

## 変更ファイル

- `js/generator.js`：モード、構成パターン、白リスト、抽選・シャッフル、証明ルート、予備問題、ヒント。
- `js/generation-worker.js`：画面を止めない問題生成。
- `js/engine.js`：設定サイズ、辞書索引、辞書全体のメモ化探索。既存の交換・長語優先・消去・履歴を継承。
- `js/app.js`：問題開始・新問題、Worker管理、ヒント、クリア学習表示。
- `index.html`・`css/style.css`：モード説明、ヒント・新問題ボタン、正方形マス。
- `data/fallbacks.json`・`scripts/build-fallbacks.mjs`：27問の予備問題と生成ツール。
- `tests/generator.test.js`・`tests/browser.mjs`・`scripts/validate.mjs`：ランダム版検証。

旧固定問題の `data/stages.json`、旧インデックス `data/terms.json` と開発スクリプトは回帰テスト用に保存してあり、現在のゲーム画面からは読みません。盤面サイズは `gridSize` として分離していますが、初級は5×5、中級は6×6で同じエンジンを使用します。
